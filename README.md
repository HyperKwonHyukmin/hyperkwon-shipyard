# 조선소 월드 (hyperkwon-shipyard)

밤의 조선소를 3D로 거니는 개인 프로젝트. Three.js만 쓰고 프레임워크는 쓰지 않는다.
모델 파일 대신 기본 도형(상자·원통)을 조합해 만든다.

## 실행

```
npm install
npm run dev      # http://127.0.0.1:8797/
npm run build    # dist/ 에 정적 파일
```

## 구조

- `index.html`: 페이지 틀(제목·안내 문구)
- `src/main.ts`: 3D 장면 전체. 단위 m, x = 도크 길이(+x가 바다·게이트), z = 폭, y = 위(안벽 상면 0)
- `public/fonts`: Pretendard(OFL 1.1). 외부 요청 없이 쓰려고 함께 둔다

## 결정

- 2026-11-12: Habit 앱 안의 화면(`/dock`)으로 시작했다가 **별도 프로젝트로 분리**. 습관 기록과는 연결하지 않고 월드 자체를 키운다.
- 곡면은 최소화한다. 선수·선미 곡면에 욕심내면 시간이 끝없이 든다.

## 확인 안 된 것

- 휴대폰 폭 화면, 실제 GPU에서의 프레임 속도.
