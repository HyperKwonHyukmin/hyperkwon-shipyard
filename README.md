# HD현대중공업 울산조선소 이야기 (hyperkwon-shipyard)

울산조선소를 무대로 배 한 척이 만들어지는 과정을 장소별로 둘러보는 3D 비공식 개인 프로젝트(계획은 `PLAN.md`, 원칙은 `CLAUDE.md`). Three.js만 쓰고 프레임워크는 쓰지 않는다.
모델 파일 대신 기본 도형(상자·원통)을 조합해 만든다.

## 실행

```
npm install
npm run dev      # http://127.0.0.1:8797/
npm run build    # dist/ 에 정적 파일
```

## 구조

- `index.html`: 페이지 틀(제목·안내 문구)
- `src/main.ts`: 도크·크레인·조명 등 장면. 단위 m, x = 도크 길이(+x가 바다·게이트), z = 폭, y = 위(안벽 상면 0)
- `src/erection.ts`: 탑재 애니메이션(블록 하나당 단계 7개: 운반·훅 내림·걸기·들기·이동·안착·훅 올림). 블록당 약 40초
- `src/welding.ts`: 용접 불꽃. 블록이 앉으면 이음매 3곳에서 16~26초 용접(아크 깜빡임, 불꽃 입자, 푸른 점광원, 화면 고정 크기 번짐). 점광원은 3개를 미리 만들어 켜고 끄기만 한다(개수가 바뀌면 셰이더 재컴파일로 멈칫함)
- `src/atmosphere.ts`: 안개(정문부터 안벽까지 땅 바로 위에 눕힌 판 60장이 흘러감. 세운 스프라이트는 땅과 맞닿는 곳에 직선이 생겨서 눕힘), 투광등 빛줄기(원뿔, 가산 혼합)
- `src/daynight.ts`: 낮 / 밤 전환(기본 낮, 오른쪽 위 버튼, 선택은 브라우저에 저장). 장면을 한 번 훑어 밤 기준값을 기억하고, 낮에는 하늘, 안개, 해, 바다 색을 바꾸고 투광등은 끄고 점광원은 35%로 줄인다. 창 불빛 그림은 낮용(밝은 벽 + 어두운 유리)을 따로 만들어 바꾼다. 별, 도시 불빛, 빛줄기, 땅 안개는 밤에만
- `src/sound.ts`: WebAudio 합성 소리. 음원 파일 없음. 브라우저 정책상 '소리 켜기' 버튼을 눌러야 시작
- `src/content/stations.ts`: 장소 11곳의 이름·공정·설명·공개 기록과 출처·카메라 위치. 문장은 여기서만 고친다
- `src/yard.ts`: 압축한 조선소 배치(도로, 장소 건물 자리, 안벽, 부표, 번호 팻말)
- `src/tour.ts`: 장소 이동(카메라 비행), 설명 패널, 지도, 방문 기록(브라우저 저장), 주소 `#장소id`
- `src/factory/shed.ts`: 공장 공용 부품. 안이 보이는 건물(도로 쪽 긴 벽을 비우고 지붕은 뒤쪽 절반만), 천장 크레인, 크레인 단계 도우미(`craneSteps`: 옮기기, 훅 높이, 잡기, 놓기), 단계 진행기(`sequence`), 불꽃 입자
- `src/factory/cutting.ts`: 강재 가공공장. 강판 반입 → 절단기가 부재 3개 외곽선을 따라 자름(강판 표면 그림에 절단선이 남음) → 자석 크레인이 부재를 팔레트로, 남은 뼈대를 스크랩 통으로. 옆 프레스는 따로 6번 눌러 강판을 굽힘. 한 순환 약 75초
- `src/factory/assembly.ts`: 조립공장. 블록 하나(12×8×3 m, 이중저 모양)를 약 130초에 만든다: 정반 위 강판에 보강재 5개 → 용접 로봇 5대(소조립) → 크레인으로 대조립장에 옮겨 늑판·거더 묶음과 위판을 덮고 용접(중·대조립) → 의장 받침에서 배관 3줄(선행의장) → 트랜스포터가 받쳐 들고 열린 면으로 반출. 도로에서 보면 +x 가 왼쪽이라 소조립을 +x 끝에 둬서 왼쪽 → 오른쪽으로 읽힌다
- `src/factory/pe.ts`: 선행탑재장(야외 마당, 골리앗형 크레인). 약 190초 순환: 1차 — 바닥 블록 + 옆 블록 → L자 블록 → 용접 → 도장공장으로 / 2차 — 도장을 마친 L자 블록 둘(선저 바깥은 빨강)을 마주 붙여 U자 단면 → 용접 → 도크로. 블록은 트랜스포터가 도로 쪽에서 실어 오고 실어 간다
- `src/factory/paint.ts`: 도장공장. 약 55초 순환: 1차 선행탑재를 마친 L자 블록 반입 → 표면처리 부스(분사 머리가 지나가며 프라이머색 → 밝은 강판색, 먼지) → 도장 부스(바닥 바깥 선저 도료 빨강, 내저판과 옆 블록 회청색, 분무) → 건조(벽 히터가 붉게) → 반출. 색 변화는 블록을 길이 방향 7조각으로 나눠 분사 머리가 지나간 조각부터 바꾼다. 점광원은 1개만(부스 앞쪽 낮은 곳), 부스 조명은 발광 재질
- `src/traffic.ts`: 블록 흐름 연결. 장소의 `flow`(out)마다 트랜스포터 한 대가 도로로 오간다(가공 → 조립 → PE장 → 도장 → PE장 → 도크 뒤 적치장). 공장 안 순환과 시간은 맞추지 않는다. 같은 `flow` 데이터로 설명 패널 '블록 흐름'(누르면 그 장소로)과 지도 화살표를 그린다
- `src/launch.ts`: 진수. 탑재가 26개 끝나면(탑재는 `holdAtEnd`로 기다림) 6초 뒤 시작: 크레인 물러남 → 도크에 물 채움(물이 흘수 7 m 를 넘으면 배가 뜸) → 게이트가 떠서 바다 쪽, 다시 옆으로 비킴 → 예인선 두 척이 배를 끌어냄 → 게이트 닫고 물 뺀 뒤 탑재를 0개부터 다시. 약 80초. 진수 장소 패널의 '진수 바로 보기'는 탑재를 다 끝난 상태로 옮긴다. 건조 시점 막대를 움직이면 진수를 멈추고 제자리로 돌린다
- `src/quay.ts`: 의장 안벽(후행의장). 도크와 따로 둔 배 한 척으로 약 190초 순환: 예인선이 배를 옆으로 밀어 안벽에 붙임 → 계류줄 4가닥 → 안벽 크레인(레일로 x 이동, 지브를 세웠다 눕혀 반경 조절)이 부두에 내려 둔 갑판 크레인 4기와 구명정을 차례로 배에 올림(놓을 때마다 받침 용접 불꽃) → 계류 시운전(연돌 연기) → 줄을 풀고 시운전 해역 쪽으로 떠남. 진수 장면과 시간은 맞추지 않는다. 바다 쪽에서 보면 +x 가 왼쪽이라 크레인은 +x 의장품부터 올린다. 조명은 밤 투광등 1개(점광원은 낮 바다에 하얀 반사 얼룩이 생겨 쓰지 않음)
- `src/trial.ts`: 시운전. 도크, 안벽과 따로 둔 배 한 척으로 약 165초 순환: 해역에 들어옴 → 속력 시험(표지 부표 두 개 사이) → 선회 시험(키를 끝까지, 1바퀴 반) → 지그재그 시험(키를 좌우 20도씩, 돌아오는 방향) → 긴급 정지(전속 후진, 고물 물거품) → 돌아감. 간단한 운동 모델(속력은 목표값으로 서서히, 회두 각속도 = 속력 × 키각 / 선회 반경, 돌 때 바깥으로 기욺)을 0.05초씩 잘게 적분해 ×16 에서도 같은 항적. 속력 12 m/s, 선회 반경 75 m 는 화면 폭(약 500 m)에 항적이 들게 줄인 값(모의 계산으로 x 약 500~910, z 약 -155~0). 항적은 가장자리가 흐린 판을 떨어뜨려 퍼지게 한다. 조명 없음(항해등은 발광 재질)
- `src/berth.ts`: 안벽에 배를 대는 공용 부품(의장 안벽과 인도 안벽). 계류 위치(부두 가장자리 + 배 반폭 + 1.5 m), 계류줄 4가닥, 예인선 두 척(옆구리를 미는 자리, 뱃머리 앞에서 끄는 자리)
- `src/delivery.ts`: 명명식과 인도. 시운전을 마친 배(만선기를 닮)가 뱃머리를 육지 쪽(-x)으로 대고 약 90초 순환: 예인선 접안 → 계류 → 손님 입장 → 대모가 줄을 끊으면 진자처럼 매달린 병이 선체 옆에 부딪혀 깨짐 → 오색 종이와 뱃고동(`sound.horn`) → 인도 서명, 고물 깃대에 선주 깃발(단색) → 줄을 풀고 떼어 낸 뒤 뱃머리를 바다 쪽으로 돌려(π → 2π, 반대로 돌면 뱃머리가 부두를 침) 첫 항해. 조명은 밤 투광등 1개
- 장소의 `look`(선택): 카메라가 바라볼 점. 오른쪽 설명 패널에 가리지 않게 건물을 화면 왼쪽으로 옮길 때 쓴다(조립공장). 지금 장소의 팻말은 카메라가 140 m 안으로 오면 흐려진다
- 공장 장면은 카메라가 바라보는 곳에서 260 m 안에 있을 때만 움직인다(`main.ts` `updateFactories`). 설명 패널의 '지금' 줄에 진행 중인 작업이 나온다. 속도 버튼(×1/×4/×16)은 도크와 공장에 함께 적용
- `src/ship.ts`: 벌크선과 블록 26개. 평행부는 단면을 밀어낸 각기둥, 선수·선미는 단면을 이어 붙인 로프트. `order`가 탑재 순서
- `public/fonts`: Pretendard(OFL 1.1). 외부 요청 없이 쓰려고 함께 둔다

## 확인용 주소 옵션

- `?blocks=N`: N개가 이미 앉은 상태에서 탑재 시작(`?blocks=26&t=40#launch` 면 진수 중간)
- `?still`: 애니메이션 없이 멈춤(기본은 전부 탑재된 모습, `?blocks=N`과 함께 쓰면 N개)
- `?t=초`: 애니메이션을 그만큼 미리 진행(헤드리스 캡처는 프레임이 드물어 이것으로 원하는 순간을 찍음)
- `#장소id`: 그 장소에서 시작(gate, design, cutting, assembly, pe, paint, dock, launch, quay, trial, delivery)
- `?map`: 지도를 연 채로 시작(캡처용)
- `?q=0~5`: 품질 단계를 직접 정함(0 전부 켬 ~ 5 가장 가볍게). 저장된 단계를 되돌릴 때도 `?q=0`
- `?stats`: 왼쪽 아래에 성능 숫자(초당 프레임, 해상도 배율, 그리기 호출, 삼각형, 켜진 조명 수)
- `?lift=각도,치우침`: 인양 학습을 그 값으로 시작. 예) `?lift=30,2&cam=12,24,118,-24,9,82#dock`
- `?bm=파도,적재`: 설계동 종굽힘 체험을 그 경우로 고정(파도 still·hog·sag, 적재 even·middle·ends). 예) `?bm=hog,ends#design`
- `?night` / `?day`: 밤 또는 낮으로 시작(저장된 선택보다 먼저)
- `?cam=x,y,z,tx,ty,tz`: 시점 고정(캡처용). 예) 선수 `?cam=107,-5,20,84,-6,0`
